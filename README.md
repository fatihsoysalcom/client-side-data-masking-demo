# Client Side Data Masking Demo

This example demonstrates client-side data masking, simulating how a 'MaskAgent' might protect sensitive user data before it is sent to a server for AI processing. It uses JavaScript to identify and replace common patterns like email addresses, phone numbers, credit card numbers, and simple name patterns within user-provided text.

## Language

`html`

## How to Run

1. Save the code as `index.html`.
2. Open `index.html` in a web browser.
